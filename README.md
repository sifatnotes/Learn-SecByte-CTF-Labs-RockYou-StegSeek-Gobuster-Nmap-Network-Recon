## Learning Path

A practical progression is:

1. Start with **RockYou Wordlist Lab** to understand wordlist-focused challenges.
2. Continue with **StegSeek Secret Stash** and **Steg in the Shadows** for steganography.
3. Explore **Wget Web File Hijack** for web-file investigation.
4. Move through **Double Trouble Hidden Files**, **Hidden Paths 2**, and **Gobuster Dirhunt** for web content discovery.
5. Study **HTTP Trail Hidden Web Stack** and **Enum Trail** for broader web investigation and enumeration.
6. Finish with **SYN Scout Map the Network**, **Double Trouble Discovery**, and **ARP Hunt Double Trouble** for network reconnaissance.

## How to Use the Labs

1. Open each lab through its supplied Learn SecByte URL.
2. Review the lab scope and instructions before beginning.
3. Perform all exercises only within authorized lab environments.
4. Record useful observations, discovered paths, clues, and tools.
5. Focus on understanding the security concepts behind each exercise.
6. Document lessons learned for future CTF and defensive-security practice.
